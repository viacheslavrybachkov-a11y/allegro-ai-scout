# Allegro AI Scout

**Version:** 2.0.0

## Description

Allegro AI Scout is a personal application for analyzing product offers, prices, sales performance, and market trends on Allegro.

The application is developed for private use by the account owner.

## Features

- Analysis of the account owner's product offers and sales data.
- Product price and profitability calculations.
- CSV import and export.
- Product category analysis and data visualization.
- Planned integration with the official Allegro REST API.

## Technology

- Python 3.13
- Streamlit
- Pandas
- Plotly

## API Integration

The application is intended to use the official Allegro REST API with OAuth 2.0 authorization and read-only permissions.

It does not modify offers or orders.

## Security

API credentials and access tokens are stored locally and are not published in this repository.
